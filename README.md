## Professional Summary

Backend engineer with a foundation in Go, Rust, Java and C, progressing toward enterprise
security engineering. Areas of interest span decentralised finance, with particular attention
to stablecoin systems, and conventional low-level and enterprise software. Current work
concentrates on how systems fail: broken access control, unsafe input handling, and defects
